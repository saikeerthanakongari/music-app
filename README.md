# Lyriks Music App 🎵

## Description
This is a music player application built with React. It features a modern user interface where users can discover new songs, play music, and view top charts.

## Features
* **Music Player:** Play, pause, and skip songs.
* **Discover:** Browse popular hits with album art.
* **Responsive:** Works on desktop and mobile.

## How to Run

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Start the app:**
    ```bash
    npm run dev
    ```

## Technologies Used
* React.js
* Tailwind CSS
* Vite
